# Kucher — автономная демонстрационная версия

Эта версия не использует Node.js, Express, Prisma, PostgreSQL или удалённый API. Каталог, корзина, профиль, демонстрационные заказы и заявки работают в браузере через `localStorage`.

## Быстрый запуск

1. Распакуйте ZIP-архив в папку.
2. Откройте `index.html` в браузере. Если браузер блокирует хранение данных между HTML-файлами при открытии через `file://`, установите расширение **Live Server** в VS Code, откройте папку проекта и нажмите правой кнопкой по `index.html` → **Open with Live Server**. Node.js и backend запускать не нужно.
3. Для входа откройте «Личный кабинет» и используйте:
   - **Логин:** `admin`
   - **Пароль:** `admin`
4. Для локальной панели заявок откройте `manager.html`, код доступа — `admin`.

## Что работает

- каталог и карточки товаров;
- поиск по названию и артикулу;
- корзина и сохранение её содержимого;
- демонстрационный вход `admin / admin`;
- профиль в пределах одного браузера;
- оформление заказа, история заказов и отмена заказа с возвратом демонстрационного остатка;
- заявки менеджеру и статусы в локальной панели менеджера.

## Ограничения

Это только прототип для локальной демонстрации. Пользователь `admin` и пароль находятся в клиентском коде; вход не является настоящей защитой. Профиль, заказы, корзина и заявки хранятся локально в текущем браузере и не синхронизируются между устройствами, браузерами или компьютерами. После очистки данных браузера записи будут потеряны. Любой посетитель, имеющий доступ к исходникам, может обойти экран входа. **Не публикуйте эту версию для реальных покупок, оплаты или хранения реальных персональных данных.**

## Публикация

Можно загрузить на GitHub как статический сайт и включить GitHub Pages. Серверный хостинг не нужен. Поскольку это многосоставной статический сайт с относительными ссылками, публикуйте содержимое корня репозитория как есть.
## Каталог и изображения

В демонстрационном каталоге 100 товаров — ровно по 20 в каждой из пяти категорий. Все товары используют одну локальную SVG-заглушку `images/product-placeholder.svg`; внешние фотографии товаров не загружаются. Заглушка применяется также в карточке товара и корзине.

При первом открытии после обновления каталог синхронизирует изображения с текущими данными и сохраняет остатки по совпадающим ID товаров.
